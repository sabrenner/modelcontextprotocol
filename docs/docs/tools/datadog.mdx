## What is Datadog LLM Observability?

Datadog LLM Observability provides end-to-end tracing of LLM chains and agentic systems with visibility into input-output, errors, latency, and token usage, along with robust quality and security evaluations at each step — including data retrieval, tool calls, and agent-to-agent interactions. By seamlessly correlating LLM traces with APM and utilizing cluster visualization to identify drifts, Datadog LLM Observability enables you to swiftly resolve issues and confidently scale AI applications in production, all while ensuring accuracy, safety, and cost-efficiency.

## Installation and Setup

1. [Create a Datadog trial account](https://www.datadoghq.com/) if you do not have one.

2. [Create a Datadog API key](https://docs.datadoghq.com/account_management/api-app-keys/#api-keys) if you do not have one.

3. Install the `ddtrace` package

```bash
# using pip
pip install ddtrace

# using uv
uv add ddtrace
```

4. Set up the appropriate environment variables. You will also need to specify an ML Application name in the following environment variables. An ML Application is a grouping of LLM Observability traces associated with a specific LLM-based application, separate from the service it is part of. See [ML Application Naming Guidelines](https://docs.datadoghq.com/llm_observability/instrumentation/sdk?tab=python#application-naming-guidelines) for more information on limitations with ML Application names.

```shell
export DD_API_KEY=<YOUR_DD_API_KEY>
export DD_SITE=<YOUR_DD_SITE>
export DD_LLMOBS_ENABLED=true
export DD_LLMOBS_ML_APP=<YOUR_ML_APP_NAME>
export DD_LLMOBS_AGENTLESS_ENABLED=true
export DD_APM_TRACING_ENABLED=false
```

## Running your application

1. Install the `openai` package.

```bash
uv add openai 
```

2. Set up a FastMCP server with a single tool.

```python
"""
FastMCP quickstart example.

cd to the `examples/snippets/clients` directory and run:
    uv run server fastmcp_quickstart stdio
"""

from mcp.server.fastmcp import FastMCP

# Create an MCP server
mcp = FastMCP("Demo")


# Add an addition tool
@mcp.tool()
def add(a: int, b: int) -> int:
    """Add two numbers"""
    return a + b
```

3. Set up a client that configures the server with LLM Observability, and runs a simple react agent that uses the MCP server.

```python
import asyncio
import json
import os
from mcp.client.stdio import stdio_client, StdioServerParameters
from mcp import ClientSession
from openai import OpenAI


async def main():
    openai_client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))
    
    server_params = StdioServerParameters(
        command="ddtrace-run",  # this runs the server with ddtrace
        args=["python", "demo_server.py"],
        env=os.environ,  # this makes sure the environment variables are passed through
    )
    
    print("🚀 Demo MCP Client\n")
    
    async with stdio_client(server_params) as (read, write):
        async with ClientSession(read, write) as session:
            await session.initialize()
            
            tools_response = await session.list_tools()
            print(f"✅ Connected! Available tools: {', '.join(t.name for t in tools_response.tools)}\n")
            
            # Convert MCP tools to OpenAI format
            openai_tools = []
            for tool in tools_response.tools:
                openai_tools.append({
                    "type": "function",
                    "function": {
                        "name": tool.name,
                        "description": tool.description,
                        "parameters": tool.inputSchema or {"type": "object", "properties": {}}
                    }
                })
            
            messages = []
            
            while True:
                user_input = input("You: ").strip()
                if user_input.lower() in ['exit', 'quit']:
                    break
                
                messages.append({"role": "user", "content": user_input})
                
                response = openai_client.chat.completions.create(
                    model="gpt-4o-mini",
                    messages=messages,
                    tools=openai_tools,
                    tool_choice="auto"
                )
                
                response_message = response.choices[0].message
                messages.append(response_message)
                
                if response_message.tool_calls:
                    for tool_call in response_message.tool_calls:
                        function_name = tool_call.function.name
                        arguments = json.loads(tool_call.function.arguments)
                        
                        print(f"🔧 Calling {function_name}({arguments})")
                        
                        tool_result = await session.call_tool(function_name, arguments)
                        result_text = tool_result.content[0].text
                        
                        messages.append({
                            "role": "tool",
                            "tool_call_id": tool_call.id,
                            "content": result_text
                        })
                    
                    final_response = openai_client.chat.completions.create(
                        model="gpt-4o-mini",
                        messages=messages,
                        tools=openai_tools,
                        tool_choice="auto"
                    )
                    
                    final_message = final_response.choices[0].message
                    messages.append(final_message)
                    print(f"Assistant: {final_message.content}\n")
                else:
                    print(f"Assistant: {response_message.content}\n")


if __name__ == "__main__":
    asyncio.run(main())
```

4. Run the client with the appropriate [environment variables](#installation-and-setup) set.

```bash
ddtrace-run python client.py
```

5. In [Datadog LLM Observability's Traces View](https://app.datadoghq.com/llm/traces), confirm that the traces are being submitted to LLM Observability. Selecting the ML Application name you chose from the top-left dropdown will show you the traces for that application.
